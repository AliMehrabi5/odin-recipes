
# Odin Recipes

This is my first HTML project from The Odin Project Foundations course.

The website contains a homepage with links to three recipes: Lasagna, Pizza, and Burger.

## Skills Demonstrated

- Creating HTML boilerplate
- Using headings and paragraphs
- Adding images with alt attributes
- Creating ordered and unordered lists
- Linking pages with relative paths
- Organizing files and directories
- Using Git and GitHub to track and publish a project
